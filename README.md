# Student Project

This project is a Student Information System made using Python. It allows us to manage student information, validate student marks, calculate grades, and generate student reports. The project also uses JSON for student data, a .env file for configuration, logging for tracking application events, and pytest for testing the application. We also use Git and GitHub to manage the project, create branches, save changes, and keep the project organized. The main goal of this project is to learn how to build a simple, reliable, and well-organized Python application using professional development practices.

Week 01 — Student Information System.

## Run
python -m src.student_app.main

## Test
pytest -v
